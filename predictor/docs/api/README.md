# Контракты API

Файлы в этой директории генерируются из Go-контрактов и реестра MCP. Источник истины — код; вручную изменённые файлы будут перезаписаны.

| Файл | Содержимое |
| --- | --- |
| [`openapi.json`](openapi.json) | HTTP API Domain ↔ ESB: health, типизированные тела вызовов всех агентов, чтение результатов и фактов. Документирует сохранённый GET с JSON-телом. |
| [`asyncapi.json`](asyncapi.json) | WebSocket `/stream` Константина: вопросы, подтверждения, ответы, исходный анализ и ошибки. |
| [`mcp-tools.md`](mcp-tools.md) | Краткий список MCP-инструментов для чтения. |
| [`mcp-tools.json`](mcp-tools.json) | Схемы `tools/list`, полученные напрямую от MCP-регистрации ESB. |

## Обновление

Из корня репозитория выполните:

```sh
make docs
make docs-check
```

OpenAPI строится из типов и метаданных в `esb/internal/presentation/httpapi/`. AsyncAPI использует те же типы кадров, которые разбирает и отправляет WebSocket-обработчик. MCP-каталог извлекается из `tools/list` сервера, сконфигурированного той же регистрацией инструментов, что и `/mcp`.

Краткие примеры и правила интеграции приведены в [руководстве Domain ↔ ESB](../integration.md). Архитектурные границы описаны в [architecture.md](../architecture.md).
