# PredictBoss — фронтенд («Альфа Пульс»)

Веб-интерфейс системы, которая анализирует новости и оценивает их влияние на компанию.
Пользователь заполняет профиль компании, добавляет источники новостей и общается с ИИ-аналитиком Константином:
получает анализ с доказательствами и задаёт уточняющие вопросы.

Дизайн: Figma `BlFseZSzFUEkh25ylStTmG` (PredictBoss), 12 фреймов, включая «UI Kit · Альфа Пульс».

## Стек

- Vite + React + TypeScript, Node.js 24 LTS.
- Стили: CSS Modules + CSS-переменные (токены в `src/styles/tokens.css`).
- Роутинг: React Router. Данные: TanStack Query. Иконки: lucide-react. Шрифт: Inter (@fontsource/inter).

## Структура

- `src/styles` — токены и глобальные стили.
- `src/ui` — UI kit: переиспользуемые компоненты, одна папка на компонент; витрина на странице `/kit`.
- `src/layouts` — каркасы (авторизация, приложение с боковым меню).
- `src/pages` — страницы, собранные только из компонентов `src/ui`.
- `src/api` — единственный слой данных: `types.ts`, функции для страниц, `mock/` и `http/`.
  Переключение — `VITE_USE_MOCKS=true|false`. Страницы не знают, откуда данные.
- `docs/API.md` — эндпоинты и форматы, которые ожидает фронтенд.

## Правила

- Работаем в ветке `front`, меняем только `predictor/frontend`. Чужой код в репозитории не трогаем.
- Бэкенд для фронтенда — сервис Domain (Егор). Напрямую в ESB не ходим: его ключ секретный.
- Цвета, размеры, отступы — только через токены, без «магических» значений в компонентах.
- У каждой страницы есть состояния: загрузка, пустой список, ошибка.
- Вход пока на моках (любой логин проходит), у пользователя одна компания.
- Только десктоп (1440, минимум 1280), русский язык, светлая тема.
- Работаем по этапам (UI kit → страницы → описание API) и после каждого ждём подтверждения.
- Пользователь — новичок во фронтенде: объяснять простыми словами, по-русски.
