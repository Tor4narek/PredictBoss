# Альфа Пульс — фронтенд PredictBoss

React-приложение использует только реальные endpoint-ы Domain API. Тестовые аккаунты, mock provider и seed-данные удалены.

## Локальный запуск

Запустите Domain API, затем выполните:

```bash
cd predictor/frontend
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Vite проксирует `/auth`, `/api`, `/swagger` и `/health` на `http://localhost:8080`.

## Docker Compose

```bash
docker compose up --build frontend domain-api domain-worker
```

Интерфейс доступен на `http://localhost:3000`; Nginx отдаёт SPA и проксирует API к Domain. JWT остаётся в `sessionStorage` браузера, ключ ESB доступен только сервисам.

## Страницы

- `/login`, `/register` — вход и регистрация через Domain.
- `/onboarding` — импорт компании по `SYNTHETIC_U` или ручной ввод всех полей профиля, добавление источников, запуск анализа.
- `/chat` — анализ и вопросы Константину через Domain → ESB.
- `/sources` — регулярные источники.
- `/materials`, `/materials/new` — реальные новости и разовые ссылки.
- `/profile` — просмотр и редактирование всех 23 изменяемых полей профиля. `SYNTHETIC_U` из CSV показывается без возможности изменить его.

Для формы собственности, возраста компании, этапа развития, численности сотрудников и типа клиента доступны варианты из CSV. ОКВЭД, город, регион и страны внешней торговли остаются текстовыми полями: в наборе слишком много разных значений для обычного списка.

Данные и история принадлежат серверу; браузер не сохраняет бизнес-данные локально.
