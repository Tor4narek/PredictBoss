# Альфа Пульс — фронтенд PredictBoss

## Запуск

Нужен Node.js 22.13+ (проверка: `node -v`).

```bash
cd predictor/frontend
npm install      # один раз: скачать библиотеки
npm run dev      # запустить, открыть http://localhost:5173/kit
```

Остановить сервер — `Ctrl+C` в терминале.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер разработки, правки видны сразу |
| `npm run build` | Проверка типов и сборка в папку `dist` |
| `npm run lint` | Проверка кода ESLint |
| `npm run preview` | Посмотреть собранную версию из `dist` |

## Как посмотреть приложение

Откройте http://localhost:5173 → «Зарегистрироваться/Войти». Пока API нет, данные берутся из моков:
подходит любой логин и пароль. Регистрация начинает с пустого аккаунта и ведёт в мастер создания компании,
вход — в демо-диалог с данными из макетов.

| Адрес | Экран |
|---|---|
| `/` , `/login`, `/register` | Лендинг, вход, регистрация |
| `/onboarding` | Мастер создания компании: профиль → источники → анализ |
| `/chat` | Диалог с Константином |
| `/sources` | Регулярные источники |
| `/materials`, `/materials/new` | Материалы и разовая ссылка |
| `/profile` | Профиль компании |
| `/kit` | Витрина UI kit |

Состояния страниц включаются параметром в адресе: `?mock=empty` — пустые данные,
`?mock=error` — ошибка сервера, `?mock=slow` — долгая загрузка. Например, `/chat?mock=empty`.
Вернуть демо-данные к исходным: в консоли браузера `localStorage.removeItem('pb.mock')` и обновить страницу.

## Что где лежит

- `src/styles/tokens.css` — токены дизайна из Figma (цвета, шрифты, отступы).
- `src/ui` — UI kit; витрина всех компонентов: `/kit`.
- `src/layouts` — каркасы: экраны входа и приложение с боковым меню.
- `src/pages` — страницы.
- `src/api` — данные: `types.ts` (форматы), `mock/` (моки), `http/` (запросы к Domain), `hooks.ts` (для страниц).
- `.env.example` — настройки (моки или реальный API).
