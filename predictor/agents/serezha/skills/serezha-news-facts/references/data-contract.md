# News and fact contract

- news_id: stable ID for this news item and the PostgreSQL conversation scope.
- source_id: ID of the source that supplied the news.
- source_url: optional URL of the source.
- news_text: cleaned source text, stored in ClickHouse.
- facts: zero or more company-independent claims.
- fact_id: generated by ESB and returned in the same order as facts.
- confidence: number from 0 to 1 expressing confidence that the source supports the fact.
- occurred_at: RFC3339 event time, or null when the text does not provide one.

ClickHouse stores the news and facts in separate tables. Each fact retains its news_id and source metadata.
